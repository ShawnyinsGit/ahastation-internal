# AhaMeet UED / UI 升级方案提案

> 状态：待讨论确认
> 分支：`design/ui-upgrade`
> 核心理念：每个 CLI backend 都是一个数字员工，和你在会议室里开会。默认是会议模式；详情/交付物可展开为独立编辑器窗口；编辑器内核支持集成开源 AI IDE（OpenCode / Hermes Agent / Pi Agent 等），用户可自助安装、切换。

---

## 一、设计方向最终确认

### 用户决策

1. **编辑器模式**：独立窗口打开（类似 Settings 独立窗口）
2. **Gallery tiles**：放在 stage 顶部
3. **入口**：数字员工详情 + 交付物都可以点击进入编辑器
4. **默认主题**：深色默认，浅色随系统适配
5. **编辑器内核**：不自研完整 IDE，而是**集成开源 AI IDE 项目**（OpenCode / Hermes Agent / Pi Agent 等），支持用户自助选择安装、切换默认 IDE

### 新定位

**AhaMeet = 数字员工视频会议工具 + 开源 AI IDE 聚合入口**

- 默认：一场标准视频会议，参会者是各个 CLI backend 数字员工
- 展开：点击详情/交付物 → 打开该数字员工的独立编辑器窗口
- 编辑器内核：可插拔的开源 AI IDE（OpenCode / Hermes / Pi 等）
- 用户可在 Settings 里安装、切换默认 IDE

## 二、双模式架构

### 2.1 会议模式（默认）

对标：**飞书会议**为主，保留现在深色质感。

#### 布局

```
┌─────────────────────────────────────────┐
│ TabStrip (32px)                         │
├─────────────────────────────────────────┤
│ MeetingHeader (48px)                    │
│  - 会议标题/目录                          │
│  - 计时器                                │
│  - 作战配置（自动批准/多 Agent）           │
│  - 设置                                  │
├─────────────────────────────────────────┤
│                                         │
│  ┌─────────────┐  ┌─────────────────┐  │
│  │             │  │                 │  │
│  │   Stage     │  │  SideDrawer     │  │
│  │  (当前主讲   │  │  (聊天/参会人)   │  │
│  │   /共享内容) │  │   320px         │  │
│  │             │  │                 │  │
│  └─────────────┘  └─────────────────┘  │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │ Gallery tiles (数字员工状态板)   │   │
│  │  - 每个 backend 一个卡片          │   │
│  │  - 头像 + 名称 + 状态 + speaking │   │
│  │  - 右上角"详情"按钮              │   │
│  └─────────────────────────────────┘   │
│                                         │
├─────────────────────────────────────────┤
│ BottomToolbar (72px)                    │
│  mic | TTS | 共享 | 截图 | 打断 | 聊天 | 结束会议 │
└─────────────────────────────────────────┘
```

#### 关键特征

- **深色默认**：保留 Apple 深色阶梯 + 毛玻璃质感
- **浅色随系统**：`:root` 深色，`@media (prefers-color-scheme: light)` 浅色覆盖
- **Gallery tiles**：每个 CLI backend 一张卡片，状态 pill + speaking 扩散环 + 详情按钮
- **Stage**：当前主讲数字员工的任务/思考/交付物预览；交付物也可点击打开编辑器

### 2.2 编辑器模式（独立窗口）

对标：**Qoder 编辑器模式**，但以独立窗口形式存在。

#### 触发方式

- 点击 Gallery tile 右上角"详情"按钮
- 点击 Stage 上的交付物（代码文件、文档等）

#### 窗口布局

```
┌─────────────────────────────────────────┐
│ ← 返回会议 | 数字员工名称 | 状态 | IDE 选择 │
├──────────┬──────────────────┬──────────┤
│          │                  │          │
│  文件树   │   代码/内容区     │  活动日志 │
│  (200px) │                  │  (240px) │
│          │                  │          │
├──────────┴──────────────────┴──────────┤
│ 终端（可折叠）                          │
└─────────────────────────────────────────┘
```

#### 关键特征

- **独立 BrowserWindow**：900×680，与 Settings 窗口类似
- **三栏 IDE 布局**：文件树 + 内容区 + 活动日志
- **IDE 选择器**：顶部下拉，切换当前使用的开源 IDE 内核
- **返回会议**：左上角按钮，关闭窗口返回会议模式
- **保持语音**：窗口打开时，TTS 和 mic 继续工作，可继续语音对话

## 三、开源 IDE 集成方案

### 3.1 支持的内核

| 项目 | 简介 | 特点 | 安装方式 |
|---|---|---|---|
| **OpenCode** | 开源 AI coding agent，terminal + desktop + IDE | 多 provider、多会话、LSP 支持 | npm / binary |
| **Hermes Agent** | Nous Research 开源 CLI agent | 自我改进技能、持久记忆、多平台 | binary |
| **Pi Agent** | 极简 agent harness | 轻量、可扩展、TypeScript 插件 | npm |
| **Claude Code** | Anthropic 官方 CLI | 当前已集成 | 已内置 |
| **Codex CLI** | OpenAI 官方 CLI | 当前已集成 | 已内置 |
| **Kimi CLI** | Moonshot 官方 CLI | 当前已集成 | 已内置 |

### 3.2 集成架构

```
┌─────────────────────────────────────────┐
│ AhaMeet 主进程                           │
│  ├─ 会议模式（当前）                      │
│  └─ 编辑器窗口管理器                     │
│      ├─ 后端适配器接口                   │
│      │   ├─ OpenCodeAdapter             │
│      │   ├─ HermesAdapter               │
│      │   ├─ PiAdapter                   │
│      │   ├─ ClaudeCodeAdapter           │
│      │   └─ CodexAdapter                │
│      └─ 独立窗口（加载对应 IDE 前端）      │
└─────────────────────────────────────────┘
```

### 3.3 用户流程

1. **安装**：Settings → 后端管理 → 选择开源 IDE → 点击安装（下载 binary / npm install）
2. **切换**：Settings → 默认 IDE → 选择默认编辑器内核
3. **使用**：会议中点击"详情" → 用默认 IDE 打开编辑器窗口
4. **临时切换**：编辑器窗口顶部下拉，临时切换当前窗口使用的 IDE

### 3.4 UI 需求

#### Settings 窗口新增"IDE 管理"面板

- 已安装 IDE 列表：名称、版本、状态、设为默认
- 可安装 IDE 列表：名称、简介、安装按钮
- 安装进度显示
- 默认 IDE 选择器

#### 编辑器窗口顶部新增 IDE 切换器

- 下拉显示已安装 IDE
- 切换后重新加载窗口内容

## 四、设计系统重构

### 4.1 主题策略

- **深色为默认**：`:root` 深色变量
- **浅色随系统**：`@media (prefers-color-scheme: light)` 浅色变量
- **不做手动切换**：跟随系统，减少复杂度

### 4.2 Token 收敛

删除双套同义变量，只保留单一语义体系：

```css
:root {
  /* 深色默认 */
  --surface-0: #1c1c1e;
  --surface-1: #2c2c2e;
  --surface-2: #3a3a3c;
  --surface-3: #48484a;
  --text-1: #f2f2f7;
  --text-2: #ebebf0;
  --text-3: #8e8e93;
  --accent: #0a84ff;
  --danger: #ff453a;
  --warn: #ff9f0a;
  --success: #30d158;
}

@media (prefers-color-scheme: light) {
  :root {
    --surface-0: #f2f2f7;
    --surface-1: #ffffff;
    --surface-2: #f7f7f9;
    --surface-3: #e5e5ea;
    --text-1: #1c1c1e;
    --text-2: #3a3a3c;
    --text-3: #6c6c70;
    --accent: #007aff;
    --danger: #d70015;
    --warn: #ff9500;
    --success: #248a3d;
  }
}
```

### 4.3 组件原语

6 个基础原语，所有业务组件必须基于它们：

| 原语 | 说明 | 变体 |
|---|---|---|
| `Button` | 统一按钮 | primary / secondary / danger / ghost，尺寸 28/32/36 |
| `Switch` | 统一开关 | 28×16，替代现在两套 |
| `Card` | 统一卡片 | default / elevated / inset |
| `Modal` | 统一弹窗 | 统一 backdrop、宽度、关闭按钮 |
| `Input` | 统一输入 | text / select / textarea，高度 32px |
| `Badge` | 统一状态标签 | 替代各组件自写的状态 pill |

## 五、界面详细设计

### 5.1 会议模式

#### Gallery tiles（数字员工状态板）

- 每张卡片 160×120px，横向排列
- 内容：头像（40px 圆形）+ 名称 + 状态 pill + speaking 扩散环
- 右上角：「详情」按钮（小图标）
- 点击卡片：选中该员工，stage 显示其内容

#### Stage

- 默认态：当前主讲数字员工的任务/思考/交付物预览
- 交付物（代码文件、文档）显示为卡片，可点击打开编辑器
- 屏幕共享态：纯黑视频区

#### BottomToolbar（72px）

```
[mic] [TTS] | [共享屏幕] [截图] [打断] | [聊天] [结束会议]
```

### 5.2 编辑器窗口

#### 顶部栏（48px）

- 左：← 返回会议
- 中：数字员工名称 + 状态 pill
- 右：IDE 切换下拉 + 关闭按钮

#### 三栏

- **文件树**：200px，该员工工作目录文件结构
- **内容区**：代码编辑器/预览，语法高亮
- **活动日志**：240px，该员工的思考、工具调用、交付记录

#### 终端

- 底部可折叠面板，默认收起

## 十、讨论点（已确认）

1. **开源 IDE 优先级**：先做 **OpenCode**
2. **编辑器窗口复用**：**允许同时打开多个**（每个数字员工一个）
3. **IDE 前端加载方式**：**独立窗口加载本地 HTML/JS**（类似 Settings 窗口）
4. **安装方式**：**内置打包**（把 OpenCode 打包进 AhaMeet App）
5. **Phase 1 范围**：**先实现 OpenCode**，后续再扩展 Hermes / Pi
